# project-bootstrap

Read the source kit's [integration guide](../../../docs/03_DELIVERY/DELIVERY_PROJECT_INSTANTIATION_GUIDE_v1.md). Identify the user's actual target project independently of the directory used to download the source.

Inspect the target's existing instructions, changes and fact sources. Reuse equivalent documents through a mapping; generate only missing governance. Run the source script's read-only plan, inspect it, then apply within the user's existing authorization. Preserve business content, uncommitted work, history and remotes. Never fill target facts with the source kit's own status.

Populate requirements, assumptions and observed facts from the target's evidence. Run the local checker and an independent recovery exercise from [the trial guide](../../../docs/03_DELIVERY/GOVERNANCE_TRIAL.md). Report measured outcomes and what remains untested. Ask only if a target or substantive conflict remains unresolved; do not introduce a confirmation round for routine additive changes already requested.
