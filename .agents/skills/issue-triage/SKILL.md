# issue-triage

Read the existing issue source, current goal and relevant evidence. Distinguish an observed defect, an unverified question and a product decision. Merge duplicate reports by linking evidence while preserving their original observations.

Prioritize by impact on the current goal and what investigation can resolve uncertainty. Give each active issue an owner or next action and an observable closure condition. Do not invent a full risk register for a routine small task.

Return the smallest useful next step and any decision that actually needs the user. Put the authoritative result in the project's existing source rather than maintaining a second summary of all progress.
