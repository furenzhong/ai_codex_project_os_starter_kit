## 3. 设计目标

### 3.1 核心目标
1. 识别当前最重要的问题 / 决策点
2. 排出主次，不一次输出过多信息
3. 生成最适合当前场景的主建议
4. 生成可执行的动作 / 指令 / 下一步
5. 在前置能力不稳定时提供可控兜底

### 3.2 非目标
- 审美绝对正确
- 无限复杂场景编排
- 长期个性化学习
- 逐帧复杂规划

## 4. 总体设计原则

### 原则 1：先判断“最大问题”，再判断“所有问题”
### 原则 2：优先输出可执行动作，而不是抽象建议
### 原则 3：优先推荐最省力的修正路径
### 原则 4：先救场，再增强
### 原则 5：一句指令只做一件事
### 原则 6：输出必须克制
