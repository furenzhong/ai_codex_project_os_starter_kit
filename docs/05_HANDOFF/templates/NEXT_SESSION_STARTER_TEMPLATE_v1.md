# 新会话启动提示模板

模板版本：v1.1。部署时填入目标项目的真实入口；这里只提供指令，不复制当前状态。

```text
请在当前项目继续工作。先读 canonical AGENTS，以及 project-os.json 映射的规则、STATUS 和 HANDOFF；没有映射时使用项目现有的明确入口。

从 STATUS 找当前任务和必要合同。区分已确认的意图、证据支持的事实与待核实假设。核对实际工作目录、代码基线和交接现场，再推进已授权的下一步。

如果已有运行会话或交付回执，先核对并续接，不重复派工或重新调用外部服务。若文档冲突，引用具体来源，依据当前合同和证据解决；确实缺少用户才能提供的信息时再提出一个具体问题。

结束时只更新发生变化的权威来源。简短报告结果、证据范围与剩余缺口；未做的检查写未测。
```

用户可以直接复制此提示。若已有等效启动入口，不再安装一份。
