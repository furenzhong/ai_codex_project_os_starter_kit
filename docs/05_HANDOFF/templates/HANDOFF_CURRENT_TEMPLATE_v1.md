模板版本：v1.1。只保存停点、现场和下一步索引。已完成／进行中／优先级的项目摘要归 STATUS；任务生命周期归任务记录；稳定规则归 AGENTS 及映射的规则文件。

## 从哪里接

- 当前状态：[STATUS 相对链接]
- 当前任务：[唯一任务记录相对链接]
- 刚停下的动作：[实际操作及停止原因，不复制整轮成果]
- 下一步入口：[任务或验收文档中的具体位置]

## 需要保留的现场

| 现场信息 | 实际值或证据 |
|---|---|
| 工作目录与基线 | [优先链接任务记录，避免再次抄写 SHA] |
| 未提交改动 | [文件、归属和用途；没有写无] |
| 仍在运行的进程或会话 | [链接任务中的会话与运行证据；未知就先核对] |
| 已形成但尚未处理的产物 | [回执／检查点／交付路径] |
| 继续前必须核实的事 | [真实不确定项；没有写无] |

不记录凭据或敏感响应。中断后先查这些现场，再恢复明确会话／检查点，不能因为上一轮没有最终回答就重新执行。

## 交接更新

只在停点或现场变化时更新。规则、目标、状态、问题表和完整日志不在这里复写；需要它们时添加相对链接。没有独立交接现场的简单任务，保留 STATUS 与任务入口即可。
