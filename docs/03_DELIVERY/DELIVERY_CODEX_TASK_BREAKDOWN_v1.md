# 工具包维护方式

每次改动从一个具体失败或使用阻碍开始：描述触发条件、期望行为、最小修正和如何观察改好。避免为模型换代批量重写规则。

| 改动 | 必要验证 |
|---|---|
| 接入或路径处理 | 隔离目标的行为测试：保留已有文件、身份检查、重复执行、冲突无写入 |
| 状态 / 交接模板 | 独立接手者能定位正确目标、现场和下一步 |
| 派工与回执 | 缺证据、错误版本、未验收结果不会被当成通过 |
| README / 导航 | 双语说明一致，链接和命令可用 |
| 工具适配说明 | 核对对应官方文档和实际启动方式，不运行未授权真实业务 |

当前阶段与待做事项只维护在 [当前状态](../00_PROJECT_CONTROL/PROJECT_CURRENT_STATUS.md)。
