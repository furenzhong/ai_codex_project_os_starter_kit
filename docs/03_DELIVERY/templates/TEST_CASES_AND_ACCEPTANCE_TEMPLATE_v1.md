## 验收判断

- 被证据支持的结论：[精确到行为、版本与范围]
- 仍未验证／有分歧：[缺口及对交付的影响]
- 必要返修：[问题及针对性复测；无则省略]
- 验收者与依据：[验收者、独立复核记录相对路径]

任务是否 accepted 只在唯一任务记录维护。进入 accepted 前，应有真实交付与相称验收证据；机器检查通过只证明结构和引用满足检查器，不证明业务语义正确。后续纠正追加并链接原证据，不改写失败原件。

治理系统本身的恢复与冲突测试，使用母仓库 GOVERNANCE_TRIAL；不要把治理试验成绩冒充业务验收。
