# 设计意图

Project OS 把项目持续性建立在仓库内的意图、事实、证据与工作现场上。用户换一个会话或工具时，接手者能够恢复正确的行动依据。

文档有成本。只有能减少误解、重复操作或返工的内容才进入日常治理；较重的领域模板按实际需要选用。规则入口、当前状态、历史记录承担不同职责。

本仓库是可复用的源工具包。将链接交给 AI 接入现有项目时，AI 提取与整合治理能力，不把源工具包的当前状态、产品定位或 Git 身份移植过去。

执行合同把意图连接到可核查结果；具体 CLI、模型和工作区只是可替换的执行方式。先用真实试验验证最小机制，再决定是否增加自动化。

产品边界见 [PRD](PRODUCT_PRD_v1.md)，事实归属见 [治理规则](../00_PROJECT_CONTROL/DOCUMENT_GOVERNANCE_SYSTEM.md)。
