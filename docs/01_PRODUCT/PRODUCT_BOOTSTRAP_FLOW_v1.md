# 接入流程

默认情境是“已有项目正在开发，用户提供本仓库链接并要求应用治理”。

1. 根据用户工作区确定目标项目，另行读取源工具包。
2. 核对目标 Git 身份、已有规则、当前任务、修改和事实来源。
3. 复用等价文档，选择最少的增量文件与映射。
4. 运行只读 plan，检查后在已有授权内 apply。
5. AI 根据目标实际材料填写目标、假设和已知事实；未知保持未知。
6. 执行机器检查及首次接手演练，返回简短结果。

空项目可以采用默认四份文档。已有成熟治理可以仅使用映射与相关合同。后续升级按差异整合，不覆盖用户填写的状态。

命令与冲突处理见 [接入指南](../03_DELIVERY/DELIVERY_PROJECT_INSTANTIATION_GUIDE_v1.md)。
