# 项目入口 / Project index

本仓库是可应用到现有项目的 AI 文档治理工具包。规则、模板和检查工具保持业务无关。

从任务出发读取，日常无需通读所有模板：

| 需要做什么 | 权威入口 |
|---|---|
| 了解本仓库现在做到哪 | [当前状态](PROJECT_CURRENT_STATUS.md) |
| 继续未完成工作 | [交接](../05_HANDOFF/HANDOFF_CURRENT.md) |
| 将治理接入现有项目 | [接入指南](../03_DELIVERY/DELIVERY_PROJECT_INSTANTIATION_GUIDE_v1.md) |
| 判断事实该放在哪 | [治理规则](DOCUMENT_GOVERNANCE_SYSTEM.md) |
| 整理工作材料、处理旧方案或判断是否该询问用户 | [文档生命周期](DOCUMENT_LIFECYCLE.md) |
| 委派给其他 Agent / 工具 | [Harness 合同](../02_TECH/HARNESS_CONTRACT.md) |
| 检验治理是否有效 | [使用试验](../03_DELIVERY/GOVERNANCE_TRIAL.md) |
| 变更结构或找正式文档 | [结构规范](PROJECT_STRUCTURE_AND_NAMING_SPEC.md)、[目录](DOCUMENT_CATALOG.md) |

机器入口为根目录 `project-os.json`。这里不复制项目进度；阶段与完成情况以当前状态为准。
