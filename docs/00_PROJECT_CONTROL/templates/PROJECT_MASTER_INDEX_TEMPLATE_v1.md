## 从哪里读

| 要回答的问题 | 唯一来源 |
|---|---|
| 应遵守哪些规则 | [canonical AGENTS／规则文件相对链接] |
| 当前有哪些证据、下一步是什么 | [STATUS 相对链接] |
| 上次停在哪里、有什么现场要保留 | [HANDOFF 相对链接] |
| 为什么采用当前方案 | [决策记录相对链接] |
| 当前任务如何执行与验收 | [从 STATUS 链接的任务与合同] |
| 文档应该放在哪里 | [项目已有结构规则相对链接；无专门需要时不新增规范] |

根目录 project-os.json 保存这些来源的机器映射。链接按部署后的实际相对位置填写，不要求项目迁移到母仓库目录。

## 更新边界

目标或入口改变时更新本文件。当前状态、任务进度、阻塞、验收结果均留在对应唯一来源，不在此保留“摘要版”。历史文档只在需要追溯时读取；链接存在不表示内容已经正确或验收已经完成。
