# 归档材料 / Archived material

这里保存已经被当前结论替代、已结束但仍有追溯价值的材料。归档目录不是默认上下文；当前规则、状态和交接不得依赖 AI 自动浏览这里的全部文件。

归档文件应说明：

- `lifecycle: archived` 或 `lifecycle: superseded`
- `archived_reason`
- `superseded_by`（如有）
- 原始日期、版本或任务编号

有未决任务依赖或用途不明的材料应继续保留在工作区，不靠归档隐藏问题。归档不等于事实正确，也不等于永久保留。删除依据项目的保留规则和已有用户授权，先检查独有内容与依赖，不能只因为文件旧、长或暂时没有链接。
